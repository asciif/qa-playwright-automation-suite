# UI Test Automation Suite (Python + Playwright)

This repository contains automated UI test scripts written in **Python** using the **Playwright** framework and `pytest`. 
These scripts are designed to verify core e-commerce functionalities, such as user authentication and checkout flows, ensuring regression stability.

## Tech Stack
* Python 3
* Playwright (Sync API)
* Pytest (Assertions and Test Runner)

## How to run
1. Clone the repository.
2. Install dependencies: `pip install pytest playwright`
3. Install browser binaries: `playwright install`
4. Run the tests: `pytest test_login.py`
